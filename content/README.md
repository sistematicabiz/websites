# Content

Text and data for the two sites, edited through the CMS (`/admin/` on the laura site).

- `laura/settings.yml`, `sistematica/settings.yml`: site-wide settings (title, default theme)
- `laura/notes/`: test collection used to prove the CMS flow
- `laura/uploads/`: images and files uploaded through the CMS

Page copy moves here in Phase 3 (laura) and Phase 4 (sistematica).
